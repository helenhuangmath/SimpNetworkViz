Reference#

Everything on this page is available from the top-level package:

import simpnetworkviz as snv

For an introduction with examples, see Using the Python API.

Workflow#

simpnetworkviz.run_pipeline(genes=None, enrichment=None, pathways=None, conditions=None, gene_sets='demo', outdir='snv_output', background=None, method='ora', fdr_cutoff=0.05, max_pathways=100, similarity_cutoff=0.375, similarity_metric='combined', use_full_gene_sets=True, cluster_method='mcl', cluster_kwargs=None, library_network=False, gene_network_mode='shared', color_by='auto', formats=('pdf', 'svg', 'html', 'cyjs', 'graphml', 'csv'), title=None, js_path=None, seed=0, dpi=300, split_updown=True, gene_network_kwargs=None, enrich_kwargs=None, pathway_map=None, species='human')[source]#

Gene list / enrichment table / pathway list / conditions -> networks + figures on disk.

Exactly one of genes (list or {gene: log2FC}), enrichment (table or path), pathways (names in gene_sets) or conditions ({name: genes}, see compare_conditions()) is the starting point; genes may also be given with the others to color gene nodes.

method: "ora" or "gsea" (genes/conditions must then carry scores for all measured genes). library_network=True draws every pathway of the library and highlights the enriched ones. cluster_kwargs passes categories, themes, louvain_resolution, mcl_inflation or hierarchical_threshold to build_pathway_network(). pathway_map (a map table or the CSV path from build_pathway_map()) adds pathway_map.pdf with the enriched pathways highlighted on the fixed library map, plus pathway_map_hits.csv and pathway_map_regions.csv. species ("human"/"mouse") selects MSigDB collections given as "msigdb:NAME" in gene_sets.

simpnetworkviz.analyze_genes(genes, gene_sets='demo', background=None, split_updown=True, method='ora', **enrich_kwargs)[source]#

Enrichment for a gene list or {gene: log2FC} dict.

method="ora": hypergeometric test. With fold changes and split_updown=True, up- and down-regulated genes are tested separately so the network can be colored red/blue.

method="gsea": preranked GSEA on the {gene: score} values (all measured genes with their statistic, not only the significant ones).

Gene sets and gene lists#

simpnetworkviz.load_gene_sets(source, min_size=1, max_size=None, species='human')[source]#

Load gene sets from a GMT path, an Enrichr library name, an MSigDB collection, "demo" or a dict.

"msigdb:GO_BP" (or "msigdb:Hallmark,msigdb:Reactome") downloads the MSigDB collection for species ("human" or "mouse"; see MSIGDB_COLLECTIONS and fetch_msigdb()). Several sources may be combined by passing a list or a comma separated string, e.g. "KEGG_2021_Human,Reactome_2022". Pathway names are prefixed with the library name only when names collide.

Hypergeometric over-representation analysis with BH correction.

Parameters:

  • gene_sets ({pathway: [genes]}, see load_gene_sets())

  • min_size (gene-set size limits (after restricting to background))

  • max_size (gene-set size limits (after restricting to background))

  • min_overlap (pathways with fewer query genes are not reported)

  • direction (optional label stored in the direction column ("up"/"down"))

simpnetworkviz.merge_conditions(table, fdr_cutoff=0.05, conditions=None)[source]#

Collapse a comparison table to one row per pathway.

Adds fdr__<condition>, direction__<condition>, nes__<condition> and genes__<condition> columns, conditions (names in which the pathway passes fdr_cutoff) and n_conditions. fdr is the best FDR, genes the union of hit genes and direction up/down when all conditions agree, else mixed.

simpnetworkviz.enrichment_matrix(table, value='fdr', fdr_cutoff=0.05, transform='neglog10')[source]#

Wide pathway x condition matrix (for heatmaps or your own plots).

value is "fdr", "nes", "fold_enrichment" or any column. With transform="neglog10" FDRs become -log10 values, signed by direction when a direction is known. Pathways not significant in any condition are dropped when fdr_cutoff is set.

simpnetworkviz.markers_to_conditions(markers, padj_cutoff=0.05, min_logfc=0.25, top_n=200, direction='up', clusters=None, rank_by='auto')[source]#

{cluster: {gene: log2FC}} from a marker table (path, DataFrame or AnnData).

direction

"up" keeps positive markers (the usual choice), "down" negative ones, "both" keeps both so up/down are tested separately.

top_n

keep the strongest top_n markers per cluster (ranked by score when present, else by abs(log2FC)); None keeps all that pass the filters.

simpnetworkviz.read_marker_table(source, sep=None)[source]#

Read a marker table into columns cluster, gene, logfc, padj, score.

Networks#

simpnetworkviz.build_pathway_network(table, gene_sets=None, fdr_cutoff=0.05, max_pathways=100, similarity_metric='combined', similarity_cutoff=0.375, use_full_gene_sets=True, cluster_method='mcl', mcl_inflation=2.0, min_cluster_size=2, label_method='auto', label_words=3, cluster_labels=None, layout='clustered', node_labels='auto', seed=0, louvain_resolution=1.0, hierarchical_threshold=None, categories=None, themes=None, highlight_only=False, conditions=None)[source]#

Build an EnrichmentMap-style pathway network.

Nodes are pathways (size = gene-set size, attributes carry FDR/direction), edges connect pathways whose gene sets overlap (similarity >= cutoff), and pathways are clustered (MCL by default) and annotated with a short label.

table is an enrichment table (DataFrame or path; see read_enrichment()). A comparison table with a condition column (compare_conditions()) gives one node per pathway with per-condition attributes, drawn as pie charts. gene_sets supplies the full pathway gene lists used for similarity (as EnrichmentMap does); use_full_gene_sets=False compares only the hit genes instead.

Grouping: cluster_method is one of CLUSTER_METHODS. category groups by pathway source (categories = {pathway: group} or the name prefix such as HALLMARK/KEGG/REACTOME), keyword by your themes ({"Theme": ["keyword", ...]}), hierarchical by average linkage on gene-set distance (hierarchical_threshold, default 1 - similarity_cutoff: clusters whose average similarity is above the edge cutoff).

highlight_only: keep rows that fail fdr_cutoff as grey "context" nodes instead of dropping them (used by build_library_network()).

simpnetworkviz.build_library_network(enrichment, gene_sets, fdr_cutoff=0.05, max_pathways=400, **kwargs)[source]#

Network of a whole gene-set library with the enriched pathways highlighted.

Every pathway of gene_sets becomes a node, so the figure shows the full landscape of the library (e.g. all 50 Hallmark sets) and which parts of it your genes, or each cell cluster's markers, fall into. Pathways absent from enrichment (or failing fdr_cutoff) are drawn as grey context nodes.

enrichment is an enrichment or comparison table (or None for the bare library). Libraries with more than max_pathways sets are trimmed to the enriched pathways plus the largest remaining sets; pass None to keep all (slow for GO-sized libraries: use Hallmark/KEGG/Reactome or a GMT subset).

simpnetworkviz.build_gene_network(pathway_network, gene_sets=None, mode='shared', clusters=None, pathways=None, gene_values=None, max_pathways=None, max_genes=150, min_shared=1, string_species=9606, string_score=400, layout=None, node_labels='auto', seed=0)[source]#

Build a gene-level network from (a subset of) a pathway network.

mode is one of:

  • "shared" genes are linked when they belong to the same pathway(s); edge weight = number of shared pathways (offline).

  • "string" protein-protein interactions from STRING (needs internet).

  • "cnet" bipartite gene-pathway "concept network" (like clusterProfiler's cnetplot).

Genes are grouped by the pathway cluster they mostly belong to, so the gene modules carry the same annotation as the pathway network. Genes come from the pathway "genes" column (your query genes); for pathway lists without query genes the full gene sets are used. gene_values (e.g. log2FC) colors the gene nodes.

simpnetworkviz.annotate_cluster(names, weights=None, max_words=3, method='auto')[source]#

Summarize a cluster of pathway names into a short label.

method="words" picks the most frequent informative words (similar to Cytoscape AutoAnnotate's WordCloud), ordered as they typically appear in the names. "representative" returns the most significant pathway name. "auto" uses words for clusters of 3+ pathways when they are shared by at least two pathways, otherwise the representative name.

{category: [pathway names]} via pathway_category().

simpnetworkviz.group_by_keywords(names, themes, other=None)[source]#

Assign pathways to user-defined themes by keyword.

themes is {"Cell cycle": ["cycle", "mitotic", "E2F"], "Immune": ["interferon", ...]}. Matching is case-insensitive on the cleaned pathway name; the first theme with a hit wins (so order themes from specific to general). Pathways matching nothing go to other (a theme name) or stay unclustered when other is None.

simpnetworkviz.pathway_category(name, mapping=None)[source]#

Source collection of a pathway name (HALLMARK, KEGG, Reactome, GO ...).

mapping ({pathway: category}, e.g. MSigDB sub-collections or your own grouping) takes precedence; unmatched names fall back to the prefix/suffix conventions of MSigDB and Enrichr, else "Other".

Pathway maps#

simpnetworkviz.build_pathway_map(gene_sets, method='auto', min_size=10, max_size=500, n_svd=50, n_neighbors=15, min_dist=0.1, cluster_resolution=1.0, min_cluster_label=5, label_words=3, seed=0)[source]#

Embed every gene set of a library in 2-D and group the map into labelled regions.

Gene sets become TF-IDF-weighted gene vectors, reduced to n_svd dimensions by truncated SVD, then embedded with method: "umap" (needs umap-learn), "tsne" (needs scikit-learn), "spectral" (no extra dependency) or "auto" (the first available in that order). Regions are Louvain communities of the k-nearest-neighbour graph, labelled like network clusters. Returns a table with MAP_COLUMNS; attrs["method"] records the embedding used. Build it once per library and save it with save_map().

simpnetworkviz.save_map(pmap, path)[source]#
simpnetworkviz.load_map(path)[source]#
simpnetworkviz.plot_pathway_map(pmap, table=None, path=None, fdr_cutoff=0.05, label_top=12, show_region_labels=True, title=None, width=11.0, dpi=300, ax=None, color_by_category=False, categories=None)[source]#

Draw the library map, with the enriched pathways of table highlighted.

Every pathway is a light grey point; region labels sit at region centres. color_by_category=True colors the points by source collection instead (pathway_category(), or categories = {pathway: category}), for a map built from several databases. Enriched pathways are drawn on top: one condition = filled circles sized by -log10 FDR; several conditions = small pie charts, one slice per condition, as in the comparison networks. The label_top most significant hits are named.

simpnetworkviz.split_by_category(gene_sets, categories=None, min_sets=1)[source]#

Split a library into {category: gene_sets}.

categories ({pathway: category}) takes precedence; otherwise the category is read from the pathway name with pathway_category(), which knows the MSigDB collection prefixes (HALLMARK, GOBP/GOCC/GOMF, KEGG, REACTOME, WP, PID, BIOCARTA, HP, MIR ...) and the "Library: pathway" names produced by load_gene_sets() for several sources. Categories with fewer than min_sets sets are dropped. Categories are returned largest first.

simpnetworkviz.build_category_maps(gene_sets, methods=('tsne', 'umap'), categories=None, min_sets=20, **map_kwargs)[source]#

One pathway map per category and embedding method.

The library is split with split_by_category() (MSigDB collections by default, e.g. a full msigdb.v2025.1.Hs.symbols.gmt gives Hallmark, GO BP, GO CC, GO MF, KEGG, Reactome, WikiPathways ... as separate maps) and build_pathway_map() is run on each category with every method in methods ("tsne" and "umap" by default). Categories with fewer than min_sets sets after the size filter are skipped with a warning, as is a method whose package is not installed. map_kwargs are passed to build_pathway_map() (min_size, max_size, n_neighbors, cluster_resolution, seed ...).

Returns {category: {method: map}}. Within a category the t-SNE and UMAP maps share their regions and labels (regions are clustered in similarity space), so only the coordinates differ.

simpnetworkviz.save_category_maps(maps, outdir, plot=True, dpi=300, formats=('pdf',))[source]#

Write every map of build_category_maps() to outdir.

Files are <category>_map_<method>.csv (reuse with --map) and, with plot=True, <category>_map_<method>.<format>. An index table category_maps.csv (category, method, n_sets, n_regions, csv, figure) is written too and returned.

simpnetworkviz.plot_category_maps(maps, path=None, table=None, fdr_cutoff=0.05, panel=4.5, dpi=300, label_top=0)[source]#

One figure with a panel per category (rows) and embedding method (columns).

table (an enrichment or comparison table) highlights the enriched pathways on each panel, as plot_pathway_map() does on a single map; label_top names the most significant hits per panel.

Plotting#

simpnetworkviz.plot_network(net, path=None, color_by='auto', node_labels='auto', show_hulls='auto', show_cluster_labels='auto', hull_style='auto', title=None, legend=True, max_width=16.0, max_height=20.0, dpi=300, edge_color='#8F8F8F', edge_alpha=0.45, cluster_label_size=14.0, node_label_size=None, font_family=None)[source]#

Draw a Network and optionally save it.

Parameters:

  • color_by ("auto", "cluster", "direction" (red up / blue down, shade = FDR),) -- "significance" (-log10 FDR), "nes", "logfc" or any numeric node attribute

  • node_labels ("auto", "all", "none", "top" (best node per cluster) or a list of node ids)

  • path (output file; the extension decides the format (png, pdf, svg, ...))

simpnetworkviz.plot_pathway_gene_network(pathway_net, gene_net, path=None, color_by='auto', gene_color_by='auto', titles=('Pathway network', 'Gene network'), panel_labels=('a', 'b'), arrangement='auto', legend=True, max_width=18.0, max_height=22.0, dpi=300, **panel_kwargs)[source]#

Two-panel figure: pathway network (a) and its gene network (b).

Both panels share cluster ids, so each cluster keeps the same outline color and label in both panels, making it easy to see which genes drive which pathway theme. arrangement is "horizontal", "vertical" or "auto" (whichever gives the more compact figure).
