map#

Overview#

snv map embeds every gene set of a library in two dimensions and saves the result as a CSV. Pass that file with --map to snv run, snv compare or snv markers to draw any analysis on the same coordinates.

Examples of command-line usage#

  1. Build the map of one library (a PDF with the same name is written too):

    snv map --gmt m5.go.bp.v2025.1.Mm.symbols.gmt -o gobp_map.csv

  2. Build it from an MSigDB collection fetched by the package:

    snv map --msigdb GO_BP --species mouse -o gobp_map.csv

  3. One t-SNE and one UMAP map per MSigDB collection:

    snv map --gmt msigdb.v2025.1.Mm.symbols.gmt --by-category -o msigdb_maps

  4. Use a map in an analysis:

    snv run genes.txt --gmt m5.go.bp.v2025.1.Mm.symbols.gmt --map gobp_map.csv

UMAP and t-SNE need the map extra: pip install "simpnetworkviz[map]".

How the map is built, how to read it and how to use the interactive version are described in The whole-library view and the pathway map.

Command-line options#

usage: snv map [-h] [--library LIBRARY] [--gmt GMT] [--species SPECIES]
               [--msigdb COLLECTION] [-o OUTPUT]
               [--method {auto,umap,tsne,both}] [--by-category]
               [--categories CATEGORIES] [--min-sets MIN_SETS]
               [--min-size MIN_SIZE] [--max-size MAX_SIZE]
               [--neighbors NEIGHBORS] [--resolution RESOLUTION] [--seed SEED]
               [--dpi DPI]

Named Arguments#

--library

Enrichr library name

--gmt

GMT gene-set file (repeatable)

--species

human or mouse (default human): picks the MSigDB collections for --msigdb and the STRING taxon

Default: 'human'

--msigdb

MSigDB collection for --species, downloaded once (Hallmark, GO_BP, GO_CC, GO_MF, Reactome, WikiPathways, BioCarta, KEGG, CP, TFT, ImmuneSigDB, CellType, All ...; repeatable; 'snv libraries' lists them)

-o, --output

map table (a PDF with the same stem is written too); with --by-category: an output folder

Default: 'pathway_map.csv'

--method

Possible choices: auto, umap, tsne, both

embedding (auto = UMAP if installed, else t-SNE; with --by-category auto/both = t-SNE and UMAP)

Default: 'auto'

--by-category

one map per category: MSigDB collection prefixes (HALLMARK, GOBP, KEGG, REACTOME ...), or one per --gmt file when several are given, or --categories FILE

Default: False

--categories

pathway<TAB>category file for --by-category

--min-sets

--by-category: skip categories with fewer sets (default 20)

Default: 20

--min-size

Default: 10

--max-size

Default: 500

--neighbors

neighbours for the embedding and the regions (default 15)

Default: 15

--resolution

region resolution (higher = more, smaller regions)

Default: 1.0

--seed

Default: 0

--dpi

Default: 300

Output files#

  • NAME.csv: the map, with one row per gene set, its coordinates and its region. Keep it with the library it was built from.

  • NAME.pdf: the map drawn without hits.

  • NAME.html: the interactive map.

  • With --by-category: a folder with <collection>_map_tsne.csv and _umap.csv, a PDF of each, the index category_maps.csv and the overview category_maps.pdf.
