run#

Overview#

snv run is the main command. It takes one of four starting points, builds a clustered pathway network and the matching gene networks, and writes the figures and tables to an output folder.

You have

You pass

What run does first

A gene list, with or without log2FC

FILE

Over-representation analysis

A ranked table of all measured genes

FILE --method gsea

Preranked GSEA

An enrichment table from another tool

--enrichment FILE

Reads the table and skips the test

A list of pathway names

--pathways FILE

Looks the pathways up in the gene sets and draws them

The input formats are described in File formats.

Examples of command-line usage#

  1. A differential expression table, one Enrichr library and a background:

    snv run degs.csv --library MSigDB_Hallmark_2020 --background measured.txt -o results

  2. Two libraries at once:

    snv run degs.csv --library KEGG_2021_Human,Reactome_2022 --background measured.txt

  3. Mouse genes against MSigDB mouse collections:

    snv run degs.csv --msigdb Hallmark --msigdb GO_BP --species mouse --background measured.txt -o results

  4. Preranked GSEA on all measured genes:

    snv run deseq2_all_genes.csv --method gsea --library MSigDB_Hallmark_2020 --fdr 0.25

  5. An enrichment table from clusterProfiler, with the gene sets it was computed from:

    snv run --enrichment clusterprofiler_result.csv --gmt c2.cp.v2024.gmt

  6. A list of pathway names:

    snv run --pathways my_pathways.txt --library GO_Biological_Process_2023

  7. The whole library with the enriched pathways highlighted:

    snv run genes.txt --library MSigDB_Hallmark_2020 --whole-library

  8. The hits drawn on a fixed library map built with snv map:

    snv run genes.txt --gmt m5.go.bp.v2025.1.Mm.symbols.gmt --map gobp_map.csv

Enrichment test: ORA or GSEA#

Over-representation analysis (default). A hypergeometric test asks whether your gene list contains more genes of a pathway than expected by chance, given the background. P-values are corrected with Benjamini–Hochberg across all gene sets of the library. With fold changes, up and down genes are tested separately (--no-split to test them together). Gene sets with fewer than 5 or more than 1000 genes are skipped (--min-size, --max-size).

snv run degs.csv --library MSigDB_Hallmark_2020 --background measured.txt

Preranked GSEA. If you would rather not choose a fold-change or p-value cutoff, give the full ranked table:

snv run deseq2_all_genes.csv --method gsea --library MSigDB_Hallmark_2020 --fdr 0.25

Gene sets of 15–500 genes are tested with the weighted Kolmogorov–Smirnov statistic and 1000 gene permutations (--permutations). The table gains es and nes columns, the figure is colored by NES, and the gene network shows the leading-edge genes. FDR 0.25 is the customary GSEA cutoff.

Enrichment only, no figures: snv enrich degs.csv --library ... -o enrichment.csv.

The settings you will adjust most often#





--fdr 0.1             # relax the FDR cutoff if few pathways pass (default 0.05)
--max-pathways 60     # fewer nodes for a cleaner figure (default 100)
--cutoff 0.5          # stricter similarity for edges = smaller, tighter clusters (default 0.375)

A run overwrites its output folder, so use -o to keep versions apart.

Command-line options#

usage: snv run [-h] [--enrichment ENRICHMENT] [--pathways PATHWAYS]
               [--library LIBRARY] [--gmt GMT] [--species SPECIES]
               [--msigdb COLLECTION] [--background BACKGROUND]
               [--method {ora,gsea}] [--no-split] [--min-size MIN_SIZE]
               [--max-size MAX_SIZE] [--permutations PERMUTATIONS] [-o OUTDIR]
               [--fdr FDR] [--max-pathways MAX_PATHWAYS]
               [--similarity {combined,jaccard,overlap}]
               [--similarity-genes {full,hits}] [--cutoff CUTOFF]
               [--cluster {mcl,louvain,greedy,label_propagation,hierarchical,components,category,keyword,none}]
               [--categories CATEGORIES] [--themes THEMES]
               [--resolution RESOLUTION] [--inflation INFLATION]
               [--linkage-threshold LINKAGE_THRESHOLD] [--whole-library]
               [--map MAP.csv] [--color-by COLOR_BY]
               [--gene-network {shared,string,cnet,none}]
               [--max-genes MAX_GENES] [--formats FORMATS] [--title TITLE]
               [--cytoscape-js CYTOSCAPE_JS] [--seed SEED] [--dpi DPI]
               [genes]

Positional Arguments#

genes

gene list (txt, one per line) or table with gene + log2FC/statistic columns

Named Arguments#

--enrichment

existing enrichment table (this tool, Enrichr, clusterProfiler, g:Profiler, GSEA)

--pathways

text file with pathway names (one per line) to draw directly

--library

Enrichr library name(s), comma separated, or 'demo'

--gmt

GMT gene-set file (repeatable)

--species

human or mouse (default human): picks the MSigDB collections for --msigdb and the STRING taxon

Default: 'human'

--msigdb

MSigDB collection for --species, downloaded once (Hallmark, GO_BP, GO_CC, GO_MF, Reactome, WikiPathways, BioCarta, KEGG, CP, TFT, ImmuneSigDB, CellType, All ...; repeatable; 'snv libraries' lists them)

--background

background/universe gene list (recommended: all measured genes)

--method

Possible choices: ora, gsea

ora = hypergeometric test on a gene list; gsea = preranked GSEA on gene + statistic for all genes

Default: 'ora'

--no-split

do not split up/down genes by log2FC sign

Default: False

--min-size

min gene-set size (default 5 ora, 15 gsea)

--max-size

max gene-set size (default 1000 ora, 500 gsea)

--permutations

gsea: gene permutations (default 1000)

Default: 1000

-o, --outdir

output folder (default: snv_output)

Default: 'snv_output'

--fdr

FDR cutoff for pathways (default 0.05)

Default: 0.05

--max-pathways

max pathways in the network (default 100)

Default: 100

--similarity

Possible choices: combined, jaccard, overlap

gene-set similarity metric (default combined = EnrichmentMap default)

Default: 'combined'

--similarity-genes

Possible choices: full, hits

compare full gene sets (EnrichmentMap default) or only the hit genes

Default: 'full'

--cutoff

similarity cutoff for edges (default 0.375)

Default: 0.375

--cluster

Possible choices: mcl, louvain, greedy, label_propagation, hierarchical, components, category, keyword, none

grouping: mcl (AutoAnnotate default), louvain, greedy, label_propagation, hierarchical, components, category (by source/--categories), keyword (--themes), none

Default: 'mcl'

--categories

TSV 'pathway<TAB>category' for --cluster category (default: name prefix)

--themes

TSV 'theme<TAB>keyword1,keyword2' for --cluster keyword

--resolution

louvain/greedy resolution (higher = more clusters)

Default: 1.0

--inflation

MCL inflation (higher = more clusters)

Default: 2.0

--linkage-threshold

hierarchical: max average distance, 1-similarity (default 1 - cutoff)

--whole-library

draw every pathway of the library and highlight the enriched ones

Default: False

--map

library map from 'snv map': also draw the enriched pathways on it (pathway_map.pdf)

--color-by

auto | cluster | direction | significance | nes | condition (pathway network coloring)

Default: 'auto'

--gene-network

Possible choices: shared, string, cnet, none

gene network type: shared pathways (offline), STRING PPI (internet), cnet, or none

Default: 'shared'

--max-genes

max genes in gene network (default 150)

Default: 150

--formats

comma separated output formats (add png for raster figures)

Default: 'pdf,svg,html,cyjs,graphml,csv'

--title

figure title

--cytoscape-js

local cytoscape.min.js to embed (offline HTML)

--seed

random seed for layouts

Default: 0

--dpi

PNG resolution in dots per inch (default 300)

Default: 300

Output files#

pathway_network.{pdf,svg,html,cyjs,graphml}, pathway_network_style.xml, pathway_network_{nodes,edges,clusters}.csv, gene_network.*, gene_pathway_network.*, cluster_barplot.{pdf,svg}, enrichment.csv, enrichment_matrix.csv (comparisons), run_params.json.

Each file is described in File formats.
