# Tutorial

Here is a collection of tutorials for SimpNetworkViz.

| Tutorial | What you learn | Needs |
|---|---|---|
| [Demo walkthrough](demo.md) | What one run produces and how to read each figure and table | Nothing; runs offline |
| [Comparing gene groups of two conditions: Cl13 vs Arm](cl13_vs_arm.md) | A real comparison of exhausted and memory CD8 T cells, from gene groups to pie-chart networks and the pathway map | The repository; internet to download mouse GO BP once |

The Cl13 vs Arm tutorial has seven steps:

* [Step 1: Get the data and the gene sets](cl13_vs_arm.md#step-1-get-the-data-and-the-gene-sets)
* [Step 2: Run the comparison](cl13_vs_arm.md#step-2-run-the-comparison)
* [Step 3: Compare Cl13 and Arm, all genes pooled](cl13_vs_arm.md#step-3-compare-cl13-and-arm-all-genes-pooled)
* [Step 4: Compare matched subgroups, TEX_Gn versus TMEM_Gn](cl13_vs_arm.md#step-4-compare-matched-subgroups-tex_gn-versus-tmem_gn)
* [Step 5: Compare the six subgroups within one condition](cl13_vs_arm.md#step-5-compare-the-six-subgroups-within-one-condition)
* [Step 6: Place every analysis on the pathway map](cl13_vs_arm.md#step-6-place-every-analysis-on-the-pathway-map)
* [Step 7: Read the tables](cl13_vs_arm.md#step-7-read-the-tables)

Its result can also be explored directly in the [interactive Cl13 vs Arm map](https://helenhuangmath.github.io/SimpNetworkViz/examples/cl13-vs-arm.html).

For the usual analysis of a single gene list, see the [standard workflow](../workflow.md).
