# Tutorial

Here is a collection of tutorials for SimpNetworkViz. They are ordered from the quickest start to the most control.

| Tutorial | What you learn | Needs |
|---|---|---|
| [Demo walkthrough](demo.md) | What one run produces and how to read each figure and table | Nothing; runs offline |
| [Analyze your own data](your_data.md) | The three starting points: a gene list, an enrichment table, a pathway list | Your data; internet for Enrichr libraries |
| [Step-by-step in Python](python.md) | Each step of the workflow as a separate call, with the choices you can make at each | Nothing; runs offline |
| [Publication figures and Cytoscape](figures.md) | Text sizes, colors, formats, the interactive viewer and Cytoscape desktop | Output from any run |

Every command and code block in the first and third tutorials runs on the bundled demo data, and the output shown is real output from those commands.
